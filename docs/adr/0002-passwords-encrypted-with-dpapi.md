# 解压密码用 Electron safeStorage 加密后存进数据库

解压密码和常用密码表不能存明文。我们用 Electron 的 `safeStorage`（Windows 上就是 DPAPI，绑定当前 Windows 用户）加密，把密文存在 SQLite 里，而不是每个密码在 Windows 凭据管理器里建一条：密码可能有几百个，跟着压缩包记录走更好管理，删记录时也不会在凭据管理器里留下垃圾。

## Consequences

- 密文只有同一台电脑、同一个 Windows 用户能解开。把绿色版拷到另一台电脑，游戏库和时长都在，但所有密码都要重新输入。界面上要能看出“这个密码解不开了”，而不是报错。
- 数据库里没法按密码查重，常用密码表的去重要先解密再比较。
