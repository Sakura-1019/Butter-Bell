# 数据库里的路径都存成相对路径

游戏文件夹存成相对于游戏目录的路径，压缩包存成相对于仓库目录的路径，启动文件存成相对于游戏文件夹的路径，封面存成相对于程序数据目录的路径。完整路径只在设置里出现一次（仓库目录、游戏目录）。这样用户换了盘符、把整个 `G:\butter` 挪到别的盘，或者用绿色版换电脑，只要在设置里改一下目录，整个库就都还能用。

## 补充（0.2.0，2026-11-04）

待解压列表里双击一个压缩包，可以单独选这一次解压到哪里，用户确认可以选到游戏目录外面（比如把大游戏放到另一个盘）。这时 `games.folder_name` 存的是**完整路径**；解压在游戏目录里的仍然只存文件夹名。代码里统一用 `path.resolve(游戏目录, folder_name)` 取游戏文件夹，两种都认。代价：游戏目录外的游戏，换盘符后要手动处理；它们也不参与“现成文件夹”扫描和按文件夹名接回。
