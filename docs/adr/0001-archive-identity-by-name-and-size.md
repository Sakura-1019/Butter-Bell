# 用“首个分卷的文件名 + 总大小”认出同一个压缩包

程序需要认出“这个压缩包以前见过”，用来接回已卸载的游戏、不重复进收件箱、记住单包密码和“不是同一套”的选择。我们用首个分卷的原始文件名加所有分卷的总字节数当压缩包的身份，不算文件哈希：仓库里有 361 项、动辄几 GB，每次扫描都算哈希太慢；而 TG 下载的文件名基本不会被改，名字加大小撞车的概率很低。

## Consequences

- 用户把压缩包改了名，程序会把它当成新的压缩包。这种情况下接回要用户手动指一下。
- 第二版按“文件名 + 大小”匹配 TG 帖子时，可以直接用同一个身份。
- 压缩包挪进“已解压”子文件夹或被移走后，身份不变，只更新它现在的位置。
